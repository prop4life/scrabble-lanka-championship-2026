How to use

  1. Create a GitHub fine-grained token with access only to scrabble-lanka-championship-2026 and Contents: Read and write.
  2. Paste the token above.
  3. Select Championship — 16 Rounds or Plate — 7 Rounds.
  4. Select the round.
  5. Choose the Pairings HTML and Standings HTML files.
  6. Click PUBLISH ROUND RESULTS.
  7. Wait a few seconds for GitHub Pages to deploy the update.

The Championship files are published under rounds/. Plate files are published under plate/. This prevents the two events from overwriting each other.
