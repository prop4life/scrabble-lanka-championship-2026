Publish Round Results

Choose a round, select the two HTML files exported by your tournament software, then click Publish. The files are sent directly to the tournament's public GitHub repository.

Security: This page uses a GitHub fine-grained Personal Access Token supplied by you. The token is kept only in this browser session and is not stored by this website. Use a token restricted to this repository with Contents: Read and write.

How to use

  1. Create a GitHub fine-grained token with access only to scrabble-lanka-championship-2026 and Contents: Read and write.
  2. Paste the token above.
  3. Select the round.
  4. Choose the Pairings HTML and Standings HTML files.
  5. Click Publish.
  6. Wait a few seconds, then open the public results page.

You can reuse the same token during the tournament by keeping this browser tab open. For security, do not share the token with anyone.
