Tournament Update Centre

Publish Round Results

Choose the event and round. You can now publish Pairings first and Standings later. You do not need to upload both files at the same time.

Security: Use a GitHub fine-grained Personal Access Token restricted to this repository with Contents: Read and write. The token is used only in this browser session and is not stored by this website.

1. Pairings

Upload the pairings as soon as they are available. Spectators will be able to view them immediately after publication.

2. Standings

After the round is completed, upload the standings separately. This will not affect the published pairings.

🏆 Championship🥉 Plate🌟 Under 12

How to use

  1. Enter your GitHub token.
  2. Select Championship, Plate, or Under 12.
  3. Select the round.
  4. Upload and publish Pairings first.
  5. Later, upload and publish Standings.

Championship files are stored under rounds/, Plate under plate/, and Under 12 under u12/.

Tip: If you publish pairings before standings, the public round page can show the pairings while the standings page remains an awaiting-results placeholder.
